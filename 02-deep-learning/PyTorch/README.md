# Deep Learning

A practical learning series covering deep learning fundamentals, neural networks, PyTorch, computer vision, object detection, and advanced architectures such as Transformers and Vision Transformers (ViT).

## Notebooks

| # | Topic |
|---|---|
| 01 | Introduction to Deep Learning |
| 02 | Mathematical Foundations for Deep Learning |
| 03 | Neural Networks from Scratch |
| 04 | PyTorch Fundamentals |
| 05 | Training and Optimization |
| 06 | Convolutional Neural Networks (CNNs) |
| 07 | Transfer Learning and Fine-Tuning |
| 08 | Model Evaluation, Generalization, and Error Analysis |
| 09 | Hyperparameter Tuning and Experiment Tracking |
| 10 | Model Interpretability and Explainable AI (XAI) |
| 11 | Object Detection with PyTorch — Faster R-CNN |
| 12 | Advanced Deep Learning with PyTorch — Attention, Transformers, and Vision Transformers (ViT) |

## Technologies

- Python
- NumPy
- Matplotlib
- PyTorch
- Torchvision
- Jupyter Notebook
- Scikit-learn

## Learning Approach

**Theory → Mathematics → Implementation → Experimentation**

Each notebook combines:

- Clear theoretical explanations
- Mathematical foundations and derivations
- Step-by-step implementations
- Fully commented code
- Practical examples and experiments
- Visualizations and model evaluation
- Exercises and further learning resources

The notebooks are designed for both independent learning and educational use.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/MobinZamanii/skills-and-learning.git
```

Install the required libraries:

```bash
pip install numpy matplotlib torch torchvision scikit-learn jupyter
```

Open the notebooks in Jupyter Notebook or JupyterLab and follow the lessons.
