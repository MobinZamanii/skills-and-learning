# Supervised Machine Learning

This section covers the fundamental concepts, mathematical foundations,
implementation, and practical applications of supervised machine learning.

The main objective is to develop a solid understanding of how supervised
learning algorithms work rather than relying solely on high-level libraries.

---

## Contents

### Regression

- Linear Regression
- Polynomial Regression

### Classification

- Logistic Regression
- K-Nearest Neighbors
- Naive Bayes
- Decision Tree
- Random Forest
- Support Vector Machine
- Gradient Boosting

---

## Learning Approach

For each algorithm, the following aspects are studied:

1. Core concept
2. Mathematical formulation
3. Algorithmic intuition
4. Training process
5. Important hyperparameters
6. Implementation from scratch
7. Implementation using Scikit-learn
8. Model evaluation
9. Visualization
10. Practical application
