# Biological Databases

A curated directory of primary resources used in the notebooks.

| Resource | Main content | URL |
|---|---|---|
| NCBI | Nucleotide, protein, literature and sequence archives | https://www.ncbi.nlm.nih.gov/ |
| Ensembl | Genome annotation and comparative genomics | https://www.ensembl.org/ |
| UniProt | Protein sequences and functional annotation | https://www.uniprot.org/ |
| GEO | Functional genomics datasets | https://www.ncbi.nlm.nih.gov/geo/ |
| SRA | High-throughput sequencing data | https://www.ncbi.nlm.nih.gov/sra |
| NCBI GDC | Cancer genomics data portal | https://portal.gdc.cancer.gov/ |
| RCSB PDB | Macromolecular structures | https://www.rcsb.org/ |
| Reactome | Curated biological pathways | https://reactome.org/ |
| Gene Ontology | Controlled vocabulary for gene function | https://geneontology.org/ |

Check each provider's current documentation, API policies, and data-use terms before downloading or redistributing data.
