# Dataset Policy and Registry

Do not commit large raw datasets or controlled-access human data to Git.

For every dataset used in a notebook, document:

- Dataset title and provider
- Accession number or stable identifier
- Organism and sample type
- Assay and data modality
- Release/version and access date
- License and usage restrictions
- Download instructions and checksums when available
- Expected local directory structure
- Preprocessing performed and provenance of derived files

Use public, de-identified datasets and respect provider terms. Controlled-access datasets require the relevant approvals and must not be redistributed.
