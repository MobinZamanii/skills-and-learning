# Unsupervised Machine Learning

This section covers the fundamental concepts, mathematical foundations,
implementation, and practical applications of unsupervised machine learning.

The main objective is to understand how machine learning models can identify
patterns, structures, and relationships in data without predefined target
labels.

## Learning Approach

For each algorithm or method, the following aspects are studied:

1. Core concept
2. Mathematical formulation
3. Algorithmic intuition
4. Training process
5. Important hyperparameters
6. Implementation from scratch when appropriate
7. Implementation using Scikit-learn or other libraries
8. Model evaluation
9. Visualization
10. Practical application

---

## Evaluation

Because unsupervised learning does not generally use predefined target
labels, evaluation methods differ from supervised learning.

### Clustering

- Silhouette Score
- Davies-Bouldin Index
- Calinski-Harabasz Index
- Inertia

### Dimensionality Reduction

- Explained Variance
- Reconstruction Error
- Visualization of learned representations
