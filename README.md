# Machine Learning, Bioinformatics and AI

This repository documents my learning and practical work in machine learning,
deep learning, bioinformatics, and artificial intelligence.

The primary goal is to develop a strong computational foundation and apply
these methods to biological and biomedical research, with a particular interest
in cancer research.

## Learning Philosophy

For each topic, I aim to study both the theoretical foundations and
practical implementation.

Whenever appropriate, algorithms are implemented from scratch before
using high-level machine learning libraries.

The learning process generally follows:

Theory
→ Mathematical Foundations
→ Implementation
→ Experimentation
→ Evaluation
→ Visualization
→ Application
