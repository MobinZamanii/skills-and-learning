# Unsupervised Learning Algorithms

This section contains practical learning materials for **Unsupervised Machine Learning algorithms** using Python.

## Requirements

```bash
pip install numpy pandas matplotlib seaborn scikit-learn
```

### Libraries

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

# Algorithms

### 1. Unsupervised Learning Fundamentals

Introduction to Unsupervised Machine Learning, covering the difference between supervised and unsupervised learning, clustering, dimensionality reduction, anomaly detection, distance metrics, feature scaling, cluster evaluation, and the practical workflow of unsupervised learning.

### 2. K-Means Clustering

Introduction and practical implementation of K-Means Clustering, covering centroids, distance-based assignment, centroid updates, the objective function, Within-Cluster Sum of Squares (WCSS), convergence, K-Means++, the Elbow Method, Silhouette Score, implementation from scratch, model evaluation, and failure cases.

### 3. Hierarchical Clustering

Introduction and practical implementation of Hierarchical Clustering, covering agglomerative clustering, linkage methods, distance metrics, dendrograms, cluster formation, choosing the number of clusters, model evaluation, and practical applications.

### 4. DBSCAN

Introduction and practical implementation of DBSCAN, covering density-based clustering, core points, border points, noise points, epsilon, minimum samples, neighborhood search, parameter selection, model evaluation, and handling non-spherical clusters.

### 5. Gaussian Mixture Models

Introduction and practical implementation of Gaussian Mixture Models (GMM), covering probability distributions, Gaussian components, mixture models, latent cluster assignments, maximum likelihood estimation, Expectation-Maximization (EM), covariance structures, soft clustering, model selection, and evaluation.

### 6. Principal Component Analysis (PCA)

Introduction to Principal Component Analysis for dimensionality reduction, covering variance, covariance, eigenvectors, eigenvalues, principal components, explained variance, projection, data reconstruction, implementation from scratch, and practical applications.

### 7. t-SNE

Introduction and practical implementation of t-SNE for nonlinear dimensionality reduction and visualization, covering pairwise similarities, high-dimensional and low-dimensional distributions, perplexity, optimization, visualization, parameter selection, and limitations.

### 8. UMAP

Introduction and practical implementation of UMAP for nonlinear dimensionality reduction and visualization, covering manifold learning, neighborhood graphs, low-dimensional embedding, hyperparameters, visualization, comparison with t-SNE, and practical applications.

More unsupervised learning algorithms will be added progressively.
